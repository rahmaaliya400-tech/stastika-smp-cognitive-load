# System Architecture & Data Flow (architecture.md)

## 1. Arsitektur Aplikasi Client-Side
Aplikasi dibangun menggunakan arsitektur ringan berbasis Web (HTML5, Tailwind CSS, JavaScript, dan Chart.js) agar berjalan lancar tanpa jeda (lag) di perangkat smartphone maupun laptop siswa.
## 2. Pengelolaan State & Skor
* Menyimpan identitas siswa/kode peserta secara lokal selama sesi belajar berlangsung.
* Menghitung skor perolehan secara otomatis pada modul permainan edukatif dan latihan soal literasi matematika.
