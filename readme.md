# StasTika.SMP - Aplikasi Belajar Statistika Berbasis Cognitive Load

Aplikasi pembelajaran interaktif yang dirancang untuk meningkatkan **Mathematical Literacy** siswa SMP pada materi Statistika (Diagram Garis & Diagram Lingkaran) melalui pendekatan **Cognitive Load Theory (CLT)**.

## Pilar Fitur Utama
1. **Anti-Overload Chunking:** Memecah teks soal cerita panjang menjadi fragmen langkah kecil.
2. **Color-Coded Math Path:** Isolasi warna tegas (Teal 100% vs Amber 360°) untuk mencegah rumus tertukar.
3. **Minimalist Interface:** Tampilan bersih bebas distraksi visual kartun sesuai temuan wawancara siswa SMPN 7 Kota Cilegon.
4. **Self-Pacing Navigation:** Kontrol penuh alur instruksi di tangan siswa.

## Cara Menjalankan Aplikasi
1. Buka file `index.html` secara langsung menggunakan browser (Chrome/Edge/Safari).
2. Atau akses secara online melalui tautan **GitHub Pages** repositori ini.
