# UI/UX Style & Layout Blueprint (desain.md)

## 1. Aturan Warna & Kontras (Prinsip Koherensi CLT)
* **Mode Persentase (%):** Menggunakan tema warna **Teal** (`#0D9488`). Semua tombol dan kotak rumus pengali 100% memakai warna aksen ini.
* **Mode Derajat Sudut (°):** Menggunakan tema warna **Amber/Orange** (`#D97706`). Semua komponen visual pengali 360° diisolasi dalam warna ini.
* **Aturan Grafik:** Dilarang menaruh gambar latar belakang ilustrasi kartun di sekitar grafik diagram utama untuk mencegah efek redundansi (distraksi perhatian).

## 2. Tata Letak Step-by-Step Task Splitter
* **Bagian Atas:** Konteks soal cerita ringkas (maksimal 2-3 kalimat padat).
* **Bagian Tengah:** Ruang kerja terfokus (hanya menampilkan 1 instruksi per layar: catat data -> hitung rumus -> lihat grafik).
* **Bagian Bawah:** Tombol navigasi kendali kecepatan belajar siswa (Sebelumnya / Selanjutnya).
